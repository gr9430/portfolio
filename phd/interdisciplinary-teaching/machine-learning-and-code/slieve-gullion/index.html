Activity 1 — Generate

This tool uses a Tracery grammar — a list of templates and word categories — to generate text fragments. The grammar here is a remix of Nick Montfort's Taroko Gorge (2009), the ur-text of procedural landscape poetry, rewritten with vocabulary drawn from Slieve Gullion, an ancient mountain in County Armagh.

Throw fragments using the control below. Then curate, don't just consume: click a fragment to select it, then click anywhere on the page to place it. Add images from the palette and your own free text. The machine supplies raw material; you arrange it into a page.

Activity 2 — Reduce

Upload one of your own photographs. The tool will reduce it to five measurements and render it three ways. Each rendering strips something the original had — and that loss is the point.

Notice what the machine can and cannot recover. The five dominant colors are extracted and offered to you in Activity 3, where you can name them in your own language and add them to the grammar.

Activity 3 — Edit Vocabulary

The grammar is a JSON object: each key is a symbol name, and each value is an array of strings. Templates in origin use #symbol# to pull a random word from that symbol's list — so "the #noun_anchor# #verb_fails#" might produce "the cairn dissolves." Edit the arrays to replace or extend the vocabulary. Leave an array empty to expose the generator's skeleton: [noun_anchor] appears where a word should be.

If you ran Activity 2, your image's dominant colors appear below the live preview. Name each color in your own language, assign it to a symbol category, and click Add — the word enters the grammar immediately and the output updates.
